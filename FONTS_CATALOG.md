## 1. Brand Typographic Direction & Architecture

UNTLD's visual world merges **raw industrial Mumbai street culture** (heavy selvedge denim, oversized silhouettes, distressed textures, oxidized metal hardware) with **strict Swiss architectural restraint** (clean grids, generous white space, micro-labels, disciplined typographic hierarchy).

To translate the iconic aesthetic seen in top-curated Pinterest minimal typography pins into a functioning, high-conversion luxury streetwear digital storefront, typography is structured into three dedicated tiers:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        UNTLD TYPOGRAPHY SYSTEM                         │
├────────────────────────────────┬───────────────────────────────────────┤
│ Tier 1: Body, UI & Neo-Grotesk │ Fonts 1–20 (Swiss Neo-Grotesque &     │
│                                │ Clean Geometric Sans)                 │
├────────────────────────────────┼───────────────────────────────────────┤
│ Tier 2: Hero & Capsule Drops   │ Fonts 21–35 (Extended Geometric,      │
│                                │ Brutalist & Editorial Display)        │
├────────────────────────────────┼───────────────────────────────────────┤
│ Tier 3: Narrative & Specs      │ Fonts 36–50 (High-Fashion Editorial   │
│                                │ Serifs & Industrial Monospace)        │
└────────────────────────────────┴───────────────────────────────────────┘
```

### B. Standard CSS Font Variables & Tokens

```css
:root {
  /* Display & Drop Headers */
  --font-display-extended: 'Unbounded', 'Panchang', sans-serif;
  --font-display-brutalist: 'Clash Display', 'Cabinet Grotesk', sans-serif;
  --font-marquee-banner: 'Anton', 'Unbounded', sans-serif;

  /* Primary UI & Neo-Grotesque Base */
  --font-base: 'Switzer', 'General Sans', 'Inter Tight', -apple-system, BlinkMacSystemFont, sans-serif;
  --font-heading: 'Switzer', 'Satoshi', sans-serif;

  /* High-Fashion Editorial Accent */
  --font-editorial: 'Instrument Serif', 'PP Editorial New', serif;

  /* Industrial Technical Monospace */
  --font-mono-spec: 'Space Mono', 'JetBrains Mono', 'DM Mono', monospace;
}

/* Micro-spec utility classes for UNTLD lookbook */
.untld-hero-title {
  font-family: var(--font-display-extended);
  font-weight: 800;
  text-transform: uppercase;
  letter-spacing: -0.02em;
  line-height: 0.95;
}

.untld-editorial-quote {
  font-family: var(--font-editorial);
  font-style: italic;
  font-weight: 400;
  letter-spacing: -0.01em;
  line-height: 1.15;
}

.untld-tech-spec-badge {
  font-family: var(--font-mono-spec);
  font-size: 11px;
  font-weight: 500;
  letter-spacing: 0.08em;
  text-transform: uppercase;
}
```

## 6. Top 5 Curated Font Pairing Systems for UNTLD

### System 1: The Raw Denim Blueprint (High-Contrast Utility)
*Best for: Raw denim capsule collection landing pages, factory spec sheets, and heavyweight garment drops.*
- **Display Hero:** `Unbounded (800)` / `Monument Extended`
- **Body & Product Grid:** `Switzer (400 / 600)`
- **Garment Technical Specs:** `Space Mono (400)`
- **Editorial Sub-header:** `Instrument Serif (Italic)`

### System 2: Contemporary Mumbai Editorial (Luxury Streetwear Minimalist)
*Best for: Brand homepage, lookbook storytelling, and flagship store showcase.*
- **Masthead & Nav:** `PP Neue Montreal (600)` / `General Sans (600)`
- **Editorial Pull Quotes:** `PP Editorial New (Italic)` / `Instrument Serif (Italic)`
- **Body Copy & PDP Accordions:** `General Sans (400)`
- **Order Metadata & SKU Badges:** `JetBrains Mono (400)`

### System 3: Brutalist Marquee Drop (High Energy & Fast Sellouts)
*Best for: Limited 24-hour flash drops, drop countdowns, and VIP password-protected releases.*
- **Marquee & Giant Banners:** `Anton (400)` & `Thunder (Condensed Maximum)`
- **Drop Category Headers:** `Panchang (700)`
- **Button CTAs:** `Satoshi (700 Uppercase)`
- **Countdown & Stock Counter:** `PP Neue Machina` / `Space Mono (700)`

### System 4: Pure Swiss Architecture (The Virgil Abloh / Minimal Post-Modern Look)
*Best for: Core brand archive, collection catalog navigation, and permanent baseline aesthetic.*
- **Primary Headers:** `Neue Haas Grotesk (700)` / `Söhne (Halbfett)`
- **Secondary Headings:** `Inter Tight (800)`
- **Body & Tabular Specs:** `Switzer (400)` & `DM Mono (400)`
- **Accents:** `Cabinet Grotesk (800)`

### System 5: 100% Free Open-Source Commercial Stack (Zero Licensing Friction)
*Best for: Instant deployment on Vercel/Shopify/Next.js without foundry licensing hurdles.*
- **Extended Display:** `Unbounded (Google Fonts)`
- **Editorial Accents:** `Instrument Serif (Google Fonts)`
- **Primary Sans:** `Switzer` or `General Sans (Fontshare CDN)`
- **Technical Monospace:** `JetBrains Mono` or `Space Mono (Google Fonts)`
